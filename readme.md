# Django + Stripe Test Task

Тестовое Django-приложение с интеграцией Stripe Checkout.

Приложение позволяет просматривать товары и заказы, создавать Stripe Checkout Session и переходить на страницу оплаты Stripe.

## Примечание по Stripe Checkout

В тестовом задании для перенаправления пользователя на страницу оплаты просят использовать `stripe.redirectToCheckout()` с `session_id`.

В документации я нашел, что `redirectToCheckout` больше не поддерживается в актуальной версии Stripe.js. Поэтому сделал как в документации Stripe сейчас:

- backend создаёт `Checkout Session` и возвращает её `id` и `url`;
- frontend получает данные с помощью `fetch()`;
- переход на Stripe Checkout выполняется через `window.location.href = session.url`.

Получилось, что требование тестового задания сохранено, но устаревший способ перенаправления заменён на актуальный.

## Запуск проекта 

Клонируйте репозиторий и перейдите в папку проекта.

Создайте файл .env на основе .env.example и укажите необходимые переменные окружения.

### Через Docker
docker compose up --build

Приложение будет доступно по адресу:

http://127.0.0.1:8000/

### Без Docker
Установите зависимости:

pip install -r requirements.txt

Примените миграции и запустите сервер:

python manage.py migrate

python manage.py runserver
